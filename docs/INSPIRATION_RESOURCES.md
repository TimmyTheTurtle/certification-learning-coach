# Inspiration shelves

Each certification has its own inspiration shelf. The tutor uses the shelf for
the track being discussed, so GH-600 examples don't accidentally become AI-103
or AI-500 guidance. Once installed, the shelves are in the project's
`training/<track>/` directories.

| Certification | Inspiration shelf | Typical use |
|---|---|---|
| GH-600 | [GH-600 resources](../training-template/gh-600/INSPIRATION_RESOURCES.md) | GitHub Copilot agents, customizations, tools, MCP, workflows, and practice-lab ideas. |
| AI-103 | [AI-103 resources](../training-template/ai-103/INSPIRATION_RESOURCES.md) | Azure AI and Foundry learning labs, fair practice questions, and application-level experiments. |
| AI-500 | [AI-500 resources](../training-template/ai-500/INSPIRATION_RESOURCES.md) | Multi-agent architecture, orchestration, evaluation, operations, security, and deployment depth. |

Every shelf is optional inspiration, not a fixed curriculum or a substitute for
the live official study guide. Each also contains a **blindside watch** for
things a learner who only follows the obvious path is likely to miss.

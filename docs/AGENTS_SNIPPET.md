# Optional `AGENTS.md` snippet

If the project has an `AGENTS.md` or other always-on instructions with planning,
approval, or record-keeping rules, add a section like this so those rules don't
conflict with ordinary tutoring. Adjust the wording to fit the project.

```markdown
## Certification Learning Coach exception

The Certification Learning Coach is a learning lab, not a project delivery
agent. When that custom agent is selected, its own instructions govern study
conversations and exploratory work. It may read the wider repository for
context, but creates, changes, and runs its learning materials and experiments
only under `training/`.

The project's planning workflow and knowledge-record rules do not apply to
ordinary tutoring conversations or to experiments contained in `training/`.
They apply again if work is proposed outside that learning lab or would make a
project-direction decision. This exception does not authorize the coach to
change files outside `training/`.
```
